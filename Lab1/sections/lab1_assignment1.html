Easiest and hardest cases of digit 8

for (r in c(a1.easiest, a1.hardest)) a1.plot_digit(r, "")

The two easiest cases were classified as 8 with high probability, and they are also easy to recognise visually: both show the characteristic shape of an 8 with two closed loops. The three hardest cases had low probabilities for the correct class and are hard to recognise even for a human. Two of them lok more like a 1 than an 8, since they are narrow and lack clear loops, and tht third could just as well be read as a 6. This suggests that the misclassifications are largely caused by unclear handwriting rather than by the model itself.

Misclassification error for different K

plot(1:30, a1.misclass.train, type = "b", col = "blue", pch = 19,
     ylim = range(c(a1.misclass.train, a1.misclass.valid)),
     xlab = "K", ylab = "Misclassification error")
lines(1:30, a1.misclass.valid, type = "b", col = "red", pch = 19)
legend("bottomright", legend = c("Training", "Validation"),
       col = c("blue", "red"), pch = 19, lty = 1)

The model complexity decreases when K increases: with K = 1 the classifier follows every single training point, while a large K averages over many neighbours and gives smoother decision boundaries. Accordingly, the training error is zero for the smallest K and increases with K, as seen in Figure 2. The validation error is lowest for small to moderate K and then increases as the model becomes too simple.

The optimal value is K = 3, where the validation error is lowest. For this K the misclassification errors are 0.0115 (training), 0.0251 (validation) and 0.024 (test). The training error is lowest since the model has seen that data. The test error is close to the validation error, so the model generalizes well to new data and the overall quality is good.

Cross-entropy for different K

The validation error was also computed as the cross-entropy

\[ CE = -\frac{1}{n}\sum_{i=1}^{n} \log\left(\hat{p}_{i, y_i} + 10^{-15}\right), \]

where \(\hat{p}_{i, y_i}\) is the predicted probability of the true class for observation \(i\).

par(mar = c(5, 5, 2, 2))
plot(1:30, a1.ce.valid, type = "b", pch = 19, col = "red",
     xlab = "K", ylab = "Cross-entropy (validation)")

According to Figure 3, the optimal value is K = 6, where the validation cross-entropy is lowest.

If the response follows a multinomial distribution, the cross-entropy equals the negative log-likelihood of the data, so minimizing it corresponds to maximum likelihood estimation. The misclassification error only counts whether a prediction is correct or not. A correct prediction with probability 0.35 counts the same as one with probability 1, and a wrong prediction made with high confidence counts the same as a narrow miss. Cross-entropy uses the full predicted probabilities and penalizes confident mistakes heavily, so it measures how well the model estimates the class probabilities and not only which class it picks.
